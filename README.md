# Candy Box 2

You have 1 candy. Eat it, throw some on the ground, ask for new features, and watch a candy counter grow into a whole ASCII world of quests, spells and lollipops.

## Play

With [av](https://asciiverse.sh), the Asciiverse client:

```
av install candybox2
av play candybox2
```

Or download the archive for your system from this repository's Releases,
unpack it and run `./candybox2` (`candybox2.exe` on Windows).

## Credits

aniwey made Candy Box in 2013 as a programming exercise; it went viral, and
he promised its sequel would be free software. Candy Box 2 came out on 24
October 2013, and the game's repository is kept by Andrei Kvapil. This
terminal edition runs aniwey's own code unchanged on a small stand-in for
the browser, compiled with QuickJS into one native program: the mouse for
buttons and tooltips, Tab and Enter without one, saves in your data folder,
the camera following you in quests wider than the screen.
